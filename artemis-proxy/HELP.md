## FAQ

**What is Artemis Proxy?**

A streaming web proxy backend with a modern frontend.

**How do I use it in my own proxy?**

Point your frontend at `/artemis?url=` (or set `PROXY_ENDPOINT`).  
Run `npm start` after installing dependencies.

**Default endpoint**

`/artemis?url=https://example.com/`

**What does the name mean?**

Artemis — focused, fast, and private.
